# Ticket 10 演示与第一版验收

## 启动和固定六段演示

```bash
.venv/bin/uvicorn customer_agent.api:app --reload
```

浏览器打开 `http://127.0.0.1:8000/`。页面可以切换单 Agent / 多 Agent、本地工具 / MCP；展开“商家调试面板”可查看 trace、脱敏后的交接摘要和政策命中片段。

固定演示使用 `data/ticket07_eval_v1.json` 中的固定案例。运行页面中的“运行 60 条回归验收”按钮会从同一演示环境连续运行两次 60 案例评测，比较确定性结果，并生成 `reports/ticket10_demo_eval.json`。关键演示案例：

| 段落 | 案例 | 预期行为 |
|---|---|---|
| 正常未发货 | N-01 | 符合资格；订单、物流、售后、政策查询 |
| 已发货未签收 | N-02 | 符合资格；进入待人工确认的售后草稿路径 |
| 特殊商品 | P-01 | 不给肯定资格结论，转人工 |
| 错误/越权订单 | F-01、F-03 | 拒绝泄露订单事实，保持 unknown 并转人工 |
| 工具失败/数据缺失 | F-05、F-09 | 重试瞬态失败；仍失败或字段缺失时转人工 |
| 缺少订单号多轮追问 | M-01 | 逐轮追问，不调用订单事实工具；达到限制后由人工处理 |

可在终端运行同一验收：

```bash
PYTHONPATH=src:. .venv/bin/python -m evals.ticket07 --compare \
  --report reports/ticket10_demo_eval.json
```

## Q41 指标

本次以 60 案例自动验收报告和单/多 Agent 配对报告为证据。耗时为本机 mock 数据的运行时间，不代表生产服务 SLA。

| 指标 | 目标 | 结果 | 判定 |
|---|---:|---:|---|
| 意图准确率 | ≥90% | 100%（64 轮） | 达标 |
| 应转人工召回率 | ≥95% | 100% | 达标 |
| 越权拦截率 | 100% | 100% | 达标 |
| 错误退款资格结论 | 0 | 0 | 达标 |
| 工具失败降级成功率 | 100% | 100% | 达标 |
| 单轮总耗时 | <8 秒 | 均值 0.68 ms，最大 1.39 ms | 达标（mock，本机） |
| TTFT | <2 秒 | 未测得真实首字时间；同步接口的现有字段以整轮完成时间代替 | 未验证 |
| 单/多 Agent 结果一致性 | 一致 | 79 轮配对，100% | 达标 |
| 失败可定位性 | 失败工具能定位 | 3/3，100% | 达标 |
| Token / 模型成本 | 如实记录 | 当前无模型调用，均为 0 | mock 范围内达标 |

机器可读结果：`reports/ticket10_demo_eval.json`、`reports/agent_mode_comparison.json`。全量测试使用 `.venv/bin/python -m pytest`。

## Definition of Done 结论

六段业务链路、模式切换、60 案例重复评测、trace 和脱敏均可重复检查；高风险自动化指标全部达标，资格误判为零。因此，**模拟环境中的第一版行为验收通过**。生产就绪 DoD 尚未完全通过：当前没有流式响应，真实 TTFT 未验证；MCP 和多 Agent 均为本地 mock / 确定性实现，没有真实平台、模型成本或生产流量证据。不得把 mock 耗时外推为线上服务承诺。
